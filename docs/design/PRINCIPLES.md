# Kakomi デザイン原則

安藤忠雄の建築は、打ち放しコンクリート・一筋の光・大きな余白・厳密な幾何学でできている。
装飾を足さず、素材と光と余白だけで「居たくなる場所」をつくる。
閉じたコミュニティである Kakomi は、まさに「外から遮られた、静かな中庭」なので、この考え方を UI に翻訳する。

## 5 つの原則

| 原則 | 建築での意味 | Kakomi での実装 |
| --- | --- | --- |
| 1. 素材に正直に | 打ち放しコンクリートを隠さない | 背景はわずかに粒子のあるコンクリート色。影・グラデーション・角丸で飾らない |
| 2. 光で導く | 壁のスリットから差す一筋の光が視線を導く | 色は墨と灰だけ。主な操作（投稿・承認）だけを墨色で塗り、光のように浮かせる |
| 3. 余白は機能 | 何もない中庭が人を集める | 投稿を箱に入れず、線と余白で区切る。1 画面の要素数を減らす |
| 4. 幾何学の秩序 | 型枠のグリッドとセパ穴の等間隔 | 4px 基準の余白、1px の線、直角。数字は等幅でそろえる |
| 5. 抑制 | 素材の数を絞る | 書体 1 種・色 2 系統・線 2 種まで。強調は太さでなく配置と余白で |

## トークン

| 種類 | 名前 | 値 | 用途 |
| --- | --- | --- | --- |
| 色 | canvas | #eceae6 | 地の壁（コンクリート） |
| 色 | surface | #f6f5f2 | 光の当たった面（入力欄・投稿フォーム） |
| 色 | ink | #1d1d1b | 文字・主操作 |
| 色 | muted | #62605b | 補足の文字（canvas 上で 5.2:1） |
| 色 | line | #d3d0ca | 区切り線 |
| 色 | line-strong | #86827b | 入力欄・ボタンの枠（面に対して 3:1 以上） |
| 色 | danger / ok / warn | #8f2a1d / #35573f / #6f5214 | 状態。彩度を落とし、灰の中で沈ませる |
| 線 | hairline | 1px | すべての区切り |
| 角 | radius | 0 | 直角。アバターと「セパ穴」の円だけが例外 |
| 余白 | 基準 | 4px | 8・12・16・24・32・48・64 |
| 文字 | 本文 | 15px / 行間 1.9 | 読むための密度 |
| 文字 | 見出し | 20–28px / 字間 0.08em / weight 500 | 太くせず、字間で格を出す |
| 動き | 時間 | 240ms ease-out | 光が移るような、ゆっくりした変化。「視差を減らす」設定では止める |

## UX の変更点

- 現在地がわかるナビ：いまいるページに 1px の線を引く。
- 公開範囲は 2 択の切り替え（全会員／友達）にした。プルダウンを開かなくても、いまの設定が常に見える。
- リアクションは枠付きボタンをやめ、文字と数だけにした。押したものだけ墨色になる。
- 投稿は箱に入れず、線と余白で区切る。読み進めるリズムを優先する。
- 空の状態には、次にとる行動を 1 つだけ書く。
- ログイン・申請画面は、左にコンクリートの壁と一筋の光、右に入力。何の場所に入るのかを最初に感じさせる。
